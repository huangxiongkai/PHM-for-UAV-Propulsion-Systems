## 2. 测试概述

**测试目标**：验证系统在无故障注入条件下的稳态运行表现。

**测试范围**：
- 故障类型：无（`TB_FAULT_NONE`）
- 验证重点：零误报、实时性能、堆栈安全、数据稳定性

---

## 3. 检测方法

**测试架构**：基于内部 Testbench 框架，`TB_FAULT_NONE` 模式下不注入任何故障，系统运行真实 ADC 采集数据。

**数据采集**：系统内部每 100ms 输出一行 MONITOR 日志，包含电压、温度、告警等级等字段。

**计时机制**：DWT Cycle Counter（72MHz），每秒输出一行 `[PERF]` 统计。

---

## 4. 参数说明

| 缩写 | 全称 | 含义 |
|------|------|------|
| ALM | Alarm Level | 告警等级：0=SAFE, 1=WARNING, 2=DANGER, 3=HARDFAULT |
| FC | Fault Cause | 故障原因枚举值 |
| Acq | Acquire Thread | 数据采集线程执行时间 |
| Pred | Predict Thread | 特征提取线程执行时间 |
| Sup | Supervisor Thread | 健康评估线程执行时间 |
| E2E | End-to-End Latency | 从采集到写回的端到端延迟 |
